# 릴스 기획: 맥북 프로 M1 터치바의 역주행

> 참고 게시물: https://www.threads.com/share/BAFVSw5soQ/ (원문은 수집하지 못함. 게시 전에 인용·캡처가 가능한지 확인할 것)

## 한 줄 컨셉
**"그때는 욕먹던 터치바, 바이브 코딩으로 부활했다"**
출시 당시 안티가 많았던 터치바가 이제는 "내 맘대로 만드는 미니 디스플레이"가 됐고, 그래서 영크크(영 크리에이터/개발 입문층)가 중고 M1 프로를 다시 찾는다는 흐름.

## 왜 지금 먹히나 (훅 근거)
- **반전 서사**: "안티 많던 기능 → 지금은 오히려 매력 포인트". 댓글 싸움(찬반)이 나기 쉬운 구조라 알고리즘에 유리함.
- **희소성**: 터치바가 달린 애플 실리콘 맥은 13인치 M1 프로(2020)와 M2 프로(2022)뿐. 그 뒤로는 단종돼서 "마지막 터치바"라는 프레임을 쓸 수 있음.
- **가성비**: 중고 M1 프로는 입문 개발·영상 편집에 여전히 충분한 성능.
- **바이브 코딩 접점**: AI한테 "터치바에 ○○ 띄워줘"라고 말만 해도 커스텀이 됨. 개발을 몰라도 결과물이 눈에 보여서 따라 하고 싶게 만듦.

## 구성안 (30~40초)

| 구간 | 화면 | 자막 / 나레이션 |
|---|---|---|
| 0~2초 **훅** | 터치바에 커스텀 위젯(예: 유튜브 구독자 수, 코인 시세, 픽셀 고양이)이 움직이는 클로즈업 | "요즘 M1 맥북 프로 다시 사는 이유, 이거임" |
| 2~7초 **과거** | 2016~2020 터치바 비판 밈과 기사 헤드라인 몽타주 | "출시 땐 '쓸데없는 기능' 소리 듣던 터치바" |
| 7~15초 **반전** | 중고 매물 캡처, "마지막 터치바" 텍스트 | "근데 이제 터치바 달린 맥은 안 나옴. 그래서 오히려 희귀템" |
| 15~28초 **핵심 데모** | AI 채팅창에 프롬프트 입력 → 코드 붙여넣기 → 터치바에 바로 반영되는 화면 녹화 (배속) | "코딩 몰라도 됨. AI한테 말로 시키면 터치바가 내 위젯이 됨" |
| 28~35초 **활용 예시** | 3컷 빠르게: 뽀모도로 타이머 / 단축키 버튼 / 음악 컨트롤 | "타이머, 단축키, 음악… 내 작업용 컨트롤러 완성" |
| 35~40초 **CTA** | 댓글 키워드 자막 크게 | (아래 CTA 참고) |

### 데모 소재 후보 (촬영 난이도순)
1. **MTMR**(오픈소스, JSON 설정) + AI가 짜준 JSON 프리셋 → 가장 쉽고 재현성 높음
2. **BetterTouchTool** 위젯 + AI가 짜준 셸/애플스크립트 → 유료지만 결과물이 예쁨
3. **Swift로 직접 만든 터치바 앱**(바이브 코딩) → 임팩트는 가장 크지만 촬영 준비 시간이 김

## CTA: 뭘로 달까?

| 옵션 | 장점 | 단점 | 적합도 |
|---|---|---|---|
| **구매 (제휴 링크)** | 즉시 수익 | 중고 기기라 제휴 링크가 마땅치 않음. "광고 영상" 인상이 생겨 공유가 줄어듦 | 낮음 |
| **만들기 클래스 홍보** | 콘텐츠 주제(바이브 코딩)와 딱 맞음. 객단가가 높음 | 첫 접점에서 바로 결제를 요구하면 전환율이 낮음 | **중~높음 (2단계로)** |
| **광고 (협찬 / 수익화)** | 운영 부담이 적음 | 릴스 자체 광고 수익은 작음. 협찬은 조회수가 쌓인 뒤에 들어오는 결과이지 CTA가 아님 | 낮음 |
| **댓글 키워드 → DM 리드마그넷** | 댓글 수 증가로 알고리즘 부스트 + DM 리스트 확보 | DM 자동화(ManyChat 등) 세팅 필요 | **높음 (1단계)** |

### 추천: "댓글 → 무료 자료 → 클래스" 2단계 퍼널
1. **릴스 CTA**: `댓글에 "터치바" 쓰면 프롬프트 + 프리셋 DM으로 보내드림`
   - 댓글이 늘어서 도달이 커지고, DM을 보낸 사람은 잠재 수강생 리스트가 됨.
2. **DM 안에서 2차 CTA**: 자료 링크 아래에 `"이런 거 직접 만들어보고 싶으면 → 디놈들 바이브코딩 만들기 클래스(대기 명단/얼리버드)"`
3. **프로필 링크**: 클래스 페이지 또는 대기 명단 폼을 고정.

이유: 이 콘텐츠의 진짜 가치는 "맥북"이 아니라 **"AI로 뭔가를 직접 만들 수 있다"**는 경험임. 구매 CTA를 달면 기기 리뷰 채널처럼 보이고, 광고는 CTA라기보다 채널이 커진 뒤 따라오는 결과임. 반면 클래스는 영상 주제와 바로 이어짐. 다만 첫 접촉에서 결제를 요구하지 말고 무료 자료로 한 번 받은 뒤 넘기는 게 전환율이 높음.

> 클래스가 아직 없다면: 같은 퍼널을 그대로 쓰되 2단계를 "클래스 오픈 알림 신청"으로 바꿔서 수요 검증용으로 활용하면 됨.

## 촬영 체크리스트
- [ ] M1(또는 M2) 13인치 맥북 프로 확보 (터치바 모델)
- [ ] 데모 1개 사전 제작 + 프롬프트 원문 저장 (DM 자료로 재사용)
- [ ] 터치바 클로즈업: 화면 밝기 최대, 주변 조명 낮춤 (터치바는 반사가 심함)
- [ ] 과거 비판 자료는 캡처 출처 표기, 원 게시물 인용 시 작성자 허락 확인
- [ ] DM 자동화 키워드 "터치바" 세팅
- [ ] 프로필 링크를 클래스/대기 명단으로 교체
