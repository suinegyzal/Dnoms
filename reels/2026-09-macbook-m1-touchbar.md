# 릴스 기획: 요즘 영크크 사이에서 맥북 프로 M1이 유행이라던데??

> 참고 게시물: https://www.threads.com/share/BAFVSw5soQ/ (원문은 수집하지 못함. 게시 전에 인용·캡처가 가능한지 확인할 것)

## 구조
- **훅 (고정)**: "요즘 영크크 사이에서 맥북 프로 M1이 유행이라던데??"
- **본문**: 터치바 역주행 이야기 (안티 많던 기능 → 단종돼서 희귀템 → 바이브 코딩으로 커스텀)
- **CTA 최종 목적지**: 디지털 수익화 판매 (추천) 또는 디지털 노마드
- 본문은 터치바 이야기 그대로 두고, **마지막 5~8초의 브릿지 멘트**로 디놈들의 주제에 연결한다.

## 구성안 (35~40초)

| 구간 | 화면 | 자막 / 나레이션 |
|---|---|---|
| 0~2초 **훅** | 터치바에 커스텀 위젯이 움직이는 클로즈업 | "요즘 영크크 사이에서 맥북 프로 M1이 유행이라던데??" |
| 2~4초 **답** | 터치바를 탭하면 위젯이 바뀜 | "이유는 딱 하나, 터치바임" |
| 4~9초 **과거** | 터치바 비판 밈이나 헤드라인 몽타주 | "출시 땐 '쓸데없는 기능' 소리 듣던 터치바" |
| 9~15초 **반전** | 중고 매물 캡처, "마지막 터치바" 텍스트 | "근데 이제 터치바 달린 맥은 안 나옴. 그래서 오히려 희귀템" |
| 15~27초 **데모** | AI 채팅창에 프롬프트 입력 → 터치바에 바로 반영 (배속) | "코딩 몰라도 됨. AI한테 말로 시키면 터치바가 내 위젯이 됨" |
| 27~32초 **브릿지** | 완성된 터치바 → (아래 CTA별 화면) | (아래 CTA별 멘트) |
| 32~38초 **CTA** | 댓글 키워드 자막 크게 | (아래 CTA별 멘트) |

- 0초부터 터치바가 움직이는 화면이어야 함. 검은 화면에 자막만 띄우는 건 금지.
- "영크크"를 모르는 시청자도 있으므로 자막 옆에 작게 (영 크리에이터) 표기를 넣는 것도 고려.

## CTA: 최종 목적지 두 가지

### ✅ 1안 (추천): 디지털 수익화 판매
**브릿지 멘트**
> "사람들이 찾는데 파는 사람이 없으면? 그게 바로 디지털 상품임.
> 방금 만든 터치바 프리셋, 이대로 올리면 팔 수 있음."

**CTA 멘트**
> "댓글에 '터치바' 남기면 프롬프트 + 이걸 상품으로 파는 법 보내드림"

**퍼널**: 댓글 "터치바" → DM (프리셋 + 프롬프트 + 판매 세팅 요약) → 디놈들 디지털 수익화 클래스 / 대기 명단

**추천 이유**: 영상에서 방금 **팔 수 있는 결과물**을 만들었기 때문에 "트렌드 → AI로 제작 → 판매"로 흐름이 끊기지 않음. 시청자는 바로 "나도 이렇게 팔 수 있겠다"로 넘어감.

### 2안: 디지털 노마드
**브릿지 멘트**
> "노트북 하나로 일하는 사람한테 터치바는 작업 컨트롤러임.
> 나는 여기에 오늘 매출이랑 주문 알림 띄워 놓고 어디서든 일함."

**CTA 멘트**
> "댓글에 '노마드' 남기면 노트북 하나로 일하는 세팅 + 터치바 프리셋 보내드림"

**퍼널**: 댓글 "노마드" → DM (작업 세팅 가이드 + 프리셋) → 디놈들 노마드 커뮤니티 / 클래스

**한계**: 터치바에서 노마드로 가려면 한 단계를 더 건너뛰어야 해서 브릿지가 1안보다 약함. 노마드 앵글은 후속편("노마드 작업용 터치바 세팅")에서 쓰는 걸 추천.

## ⚠️ 수익 표현 주의
- 판매 실적이 있을 때만 "팔았다"라고 말하고, 없으면 "팔 수 있다" 또는 "판매 도전"으로 표현.
- 매출 화면은 실제 데이터만 사용. "월 ○○만원 보장" 같은 수익 보장 표현은 쓰지 않기.

## 촬영 체크리스트

- [ ] 터치바 프리셋 1개 제작 + 프롬프트 원문 저장 (DM 자료로 재사용)
- [ ] DM 자료: 프리셋 + 프롬프트 + 판매 세팅 요약 1장

- [ ] DM 자동화 키워드 "터치바" 세팅
- [ ] 프로필 링크를 클래스/대기 명단으로 교체
