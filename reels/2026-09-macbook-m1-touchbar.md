# 릴스 기획: 맥북 프로 M1 터치바 × 디지털 노마드 / 디지털 수익화

> 참고 게시물: https://www.threads.com/share/BAFVSw5soQ/ (원문은 수집하지 못함. 게시 전에 인용·캡처가 가능한지 확인할 것)

## 원칙
디놈들 콘텐츠는 **디지털 노마드** 또는 **디지털 수익화(판매)**와 연결되어야 함.
M1 터치바 유행은 사람을 멈추게 하는 **훅**으로만 쓰고, 본론은 "노트북 하나로 돈 버는 방법"으로 넘어간다.

## 앵글 두 가지

### A안: 디지털 노마드 — "터치바 = 내 수익 대시보드"
- 터치바에 **오늘 매출, 새 주문 알림, 두 도시 시간, 환율**을 띄움.
- 메시지: "노마드는 화면 전환 없이 돈 들어오는 걸 확인한다."
- 장점: 영상이 예쁘고, 노마드 라이프스타일(카페·여행지)과 잘 붙음.

### B안: 디지털 수익화 — "터치바 위젯 만들어서 팔았다" ✅ 추천
- 바이브 코딩으로 만든 터치바 프리셋을 **디지털 상품으로 판매**(크몽, 스마트스토어 디지털 상품, Gumroad 등).
- 메시지: "코딩 몰라도 AI로 만들고, 만든 걸 파는 게 디지털 수익화."
- 장점: 디놈들 클래스(만들기 → 판매)와 영상 주제가 그대로 이어짐. 트렌드 → 제작 → 판매 과정을 한 영상에 다 보여줌.

**추천: B안을 본편으로, A안의 "매출 대시보드" 화면을 마지막 컷에 넣기**
(내가 만든 상품이 팔려서 터치바에 매출 알림이 뜨는 장면으로 마무리)

## 구성안 (B안 기준, 35~45초)

| 구간 | 화면 | 자막 / 나레이션 |
|---|---|---|
| 0~2초 **훅** | 터치바에 커스텀 위젯이 움직이는 클로즈업 | "요즘 영크크 사이에서 맥북 프로 M1이 유행이라던데??" |
| 2~5초 **이유** | 터치바를 탭하면 위젯이 바뀜 | "터치바 달린 마지막 맥이라서. 근데 난 이걸로 돈 벌었음" |
| 5~10초 **과거→반전** | 터치바 비판 밈이나 헤드라인을 빠르게 → 중고 매물 캡처 | "다들 욕하던 터치바, 이제 안 나오니까 오히려 찾는 사람이 생김" |
| 10~22초 **제작** | AI 채팅창에 프롬프트 입력 → 결과 붙여넣기 → 터치바에 바로 반영 (배속) | "코딩 몰라도 됨. AI한테 말로 시켜서 터치바 위젯 만듦" |
| 22~32초 **판매** | 상품 페이지 등록 화면(썸네일, 가격) → 판매 알림 | "찾는 사람이 있으면 상품이 됨. 만든 걸 그대로 디지털 상품으로 올림" |
| 32~38초 **노마드 컷** | 카페나 여행지에서 맥북을 여니 터치바에 "오늘 매출" 표시 | "노트북 하나로 만들고, 팔고, 확인까지" |
| 38~45초 **CTA** | 댓글 키워드 자막 크게 | "댓글에 '터치바' 남기면 프롬프트 + 판매 세팅법 보내드림" |

## 훅 문구
**메인**: "요즘 영크크 사이에서 맥북 프로 M1이 유행이라던데??"
- 0초부터 터치바가 움직이는 화면이어야 함. 검은 화면에 자막만 띄우는 건 금지.
- 2초 안에 "근데 난 이걸로 돈 벌었음"으로 **수익화 쪽으로 방향을 틀어야** 디놈들 콘텐츠가 됨.

**A/B 테스트 변형**
- A (메인): "요즘 영크크 사이에서 맥북 프로 M1이 유행이라던데??"
- B (수익화 직격): "5년 된 맥북 터치바로 돈 버는 법"
- C (노마드): "노마드들이 아직도 M1 맥북 쓰는 이유"

### 썸네일 / 첫 프레임 문구
- "요즘 영크크들이 M1 찾는 이유 (+돈 버는 법)"
- "욕먹던 터치바로 디지털 상품 만들기"

### 캡션 초안
> 요즘 영크크 사이에서 M1 맥북 프로가 다시 유행이라던데, 이유는 터치바 🔥
> 터치바 달린 애플 실리콘 맥은 M1·M2 13인치가 마지막이라 찾는 사람이 생김.
> 찾는 사람이 있으면 그게 상품이 됨.
> AI로 터치바 위젯 만들고 → 디지털 상품으로 판매까지.
> 👉 댓글에 "터치바" 남기면 프롬프트 + 판매 세팅법 DM으로 보내드림

## CTA
**퍼널: 댓글 키워드 → 무료 자료 DM → 디지털 수익화 클래스**
1. **릴스**: `댓글에 "터치바" → 프롬프트 + 판매 세팅법 DM`
2. **DM 안에서**: 자료 아래에 `"만들고 파는 과정을 처음부터 같이 해보고 싶으면 → 디놈들 클래스(얼리버드/대기 명단)"`
3. **프로필 링크**: 클래스 페이지 또는 대기 명단 폼을 고정.

구매 제휴나 광고는 이번 앵글에 맞지 않음. 이번 영상이 파는 건 맥북이 아니라 **"만들어서 파는 경험"**이기 때문.

## ⚠️ 수익 표현 주의
- 매출 화면은 **실제 판매 데이터만** 사용. 연출용 숫자를 쓰면 부업 과장 광고로 신고되거나 신뢰를 잃을 수 있음.
- 아직 판매 실적이 없으면 "팔았다" 대신 **"판매 도전 1일차"** 시리즈로 바꿔서 과정을 공개하는 편이 안전하고, 오히려 팔로우를 부르기 좋음.
- 클래스 홍보 문구에 "월 ○○만원 보장" 같은 수익 보장 표현은 쓰지 않기.

## 촬영 체크리스트
- [ ] M1(또는 M2) 13인치 맥북 프로 확보 (터치바 모델)
- [ ] 터치바 프리셋 1개 제작 + 프롬프트 원문 저장 (DM 자료로 재사용)
- [ ] 판매 페이지 등록 (크몽 / 스마트스토어 디지털 상품 / Gumroad 중 택1)
- [ ] 매출 대시보드 위젯 (실제 데이터 연동, 또는 판매 전이면 "도전 1일차"로 연출 변경)
- [ ] 노마드 컷: 카페나 여행지에서 촬영
- [ ] 터치바 클로즈업: 화면 밝기 최대, 주변 조명 낮춤 (터치바는 반사가 심함)
- [ ] DM 자동화 키워드 "터치바" 세팅
- [ ] 프로필 링크를 클래스/대기 명단으로 교체

3. **"트렌드 하나로 디지털 상품 만드는 법"** (이번 영상의 방법론을 일반화 → 클래스로 직접 연결)
