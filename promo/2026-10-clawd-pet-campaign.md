## 2. 후킹: 3초 안에 멈추게 하기

### 메인 훅 (추천) — 유행 + 즉시 반전
- **자막**: "요즘 영크크 사이에서 맥북 프로 M1이 유행이라던데??"
- **화면**: 0초부터 터치바 클로즈업. Clawd가 노트북을 두드리고 있음.
- **1.5초**: 자막 추가 "…터치바에 **이게** 살아서임"
- 왜 이걸 고르나: 사용자가 이미 고른 훅이고, 질문 → 바로 답을 화면으로 보여줘서 이탈 구간이 없음. "이게 뭐지?"가 생겨서 계속 보게 됨.

### A/B 테스트용 대안
| 안 | 훅 자막 | 타깃 | 강점 |
|---|---|---|---|
| B | "Claude한테 일 시켜놓고 10분 지나면 생기는 일" | Claude Code 사용자 | 짜증 내는 Clawd로 공감 폭발. 결말이 궁금해서 끝까지 봄 |
| C | "내 터치바에 Claude가 키우는 펫이 삼" | 맥 사용자 전반 | 설명 없이 바로 이해됨 |
| D | "다들 욕하던 터치바, 이제 이거 키우는 곳임" | 터치바 맥 보유자 | 반전 서사 |

**운영**: A를 메인으로 올리고, 3일 뒤 B를 같은 영상의 다른 버전(첫 3초만 교체)으로 올려서 비교.

## 3. 끝까지 보게 만드는 장치

1. **오픈 루프**: 첫 화면 구석에 작게 "❤️ 친밀도: 낯가림". 영상 끝에 "영혼의 단짝"이 되는 장면으로 닫음. 하트 게이지가 차는 걸 보려고 끝까지 봄.
2. **시간 카운터**: 짜증 구간에서 `· 2분` → `· 5분` → `· 10분` 자막이 올라감. 다음 단계가 궁금함.
3. **3~5초마다 장면 전환**: 같은 컷이 5초 넘게 가지 않게.
4. **마지막 반전 = 범위 넓히기**: CTA 직전에 "근데 터치바 없어도 됨"을 보여줌. 터치바 없는 시청자가 "나랑 상관없네"하고 나가지 않도록, 이 사실은 **끝에서** 공개하고 대신 첫 3초에 "끝까지 보면 터치바 없어도 되는 방법 나옴"을 아주 작게 넣는 것도 방법.

## 4. 릴스 대본 (30~35초)

| 초 | 화면 | 자막 / 나레이션 |
|---|---|---|
| 0~1.5 | 터치바 클로즈업, Clawd가 노트북 타자 중. 구석에 "❤️ 낯가림" | **요즘 영크크 사이에서 맥북 프로 M1이 유행이라던데??** |
| 1.5~4 | 같은 컷, Clawd가 폴짝 | …터치바에 **얘**가 살아서임 |
| 4~9 | Claude Code 화면 ↔ 터치바 분할. 읽기 📖 → 아령 🏋️ → 노트북 💻 | Claude가 일하면 얘도 일함. 책 읽고, 운동하고, 타자 치고 |
| 9~11 | 손 흔들며 "잠깐! Bash 써도 될까요?" | 허락 필요하면 손 흔들어서 알려줌 |
| 11~17 | `· 2분` 휴… → `· 5분` 아직이야? → `· 10분` 💢 새빨개짐 "언제 끝나!" | 근데 오래 걸리면… (10분에서) **나보다 더 화냄** |
| 17~19 | "완료!" 폴짝 | 끝나면 완료! |
| 19~25 | 톡 치기 → 쓰다듬기 하트 연사 → 간식 → 게이지가 차오르며 "친구 → 단짝 → **영혼의 단짝**" | 쓰다듬고 간식 주면 친해짐. 최종 단계는 영혼의 단짝 |
| 25~28 | 데스크톱 화면에 Clawd 6마리가 떠다님 | **근데 터치바 없어도 됨.** 화면 위에서도 삼 |
| 28~33 | 터치바 Clawd 클로즈업 + 큰 자막 | 무료임. 댓글에 **"클로드"** 남기면 링크 보내드림 |

- **엔딩 프레임**: Clawd가 "완료!" 말풍선 들고 정지 + "댓글 '클로드'". 루프되면 첫 장면(타자 치는 Clawd)으로 자연스럽게 이어지게 편집.
- **오디오**: 8비트 칩튠 BGM. 짜증 구간에서 템포 올리기.
- **화면 녹화 팁**: 터치바는 화면 녹화가 안 되므로 폰으로 실촬영(밝기 최대, 주변 어둡게). 데스크톱 모드는 화면 녹화.

## 8. 성과 측정

| 단계 | 지표 | 목표 감 |
|---|---|---|
| 멈춤 | 릴스 3초 유지율 | 60% 이상이면 훅 성공 |
| 끝까지 | 평균 시청 시간 / 완료율 | 완료율 30% 이상이면 구성 성공 |
| 반응 | 댓글 "클로드" 수 | 조회수의 1~3% |
| 클릭 | DM·스토리·스레드 링크 클릭 (UTM별) | DM 발송 대비 40% 이상 |
| **최종** | **랜딩 → 뉴스레터 구독 전환율**, 다운로드 수 (GitHub Releases 다운로드 수) | 랜딩 방문 대비 구독 10% 이상 |
